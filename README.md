# Notes

Capture thoughts or detailed notes.

# Setup

Install as a command
```
npm link
```

Uninstall as a command
```
npm link
```

# Testing

Run all tests

```bash
npm run test
```

Run a single test file
```bash
cd /path/to/file
npx jest <test-file>
```

Run a single test
```bash
npx jest <test-file> -t "<test name>"
```
